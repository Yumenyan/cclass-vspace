# 3.0 実装・確認状況（2026-11-12）

## 空間と操作

- 噴水の円形判定、回転したベンチ座面/背もたれ、噴水の縁への着席/着地、室内の椅子への着席。
- 最大ジャンプ速度を6.5m/s（高さ約1.17m）に調整。座った状態から立ち上がる足元高さを補正し、ベンチ上から高さ1.7mの仮想端末へ届く設定。
- 北東/南西に各13段の立体アスレ。順番に踏破すると25ポイント。
- 各館の裏に階段と踊り場の階移動操作。階段の段差は物理支持、高層階との接続は踊り場の操作で移動する方式。すべてを連続歩行で通り抜ける構造ではありません。
- 登録一覧からアカウント名付きの個人部屋を自動生成。6室ごとに階を追加。新規ユーザーは tools/accounts.json に追加してビルドする運用で、自己登録サーバーはありません。
- 北館中央のアトリエ2を削除し、広場編集室を追加。西館にミュージックルームを追加。
- 身長30〜200%（標準モデル180cmを基準）、ジャンプ高0〜100%、身長計、キー割り当て、自室スタート設定。

## 編集・遊び

- 広場編集室は既存の3Dプレビュー/座標編集を使用。data/plaza.jsonを書き出してリポジトリに追加すると次回配信に反映。画面上での直接ドラッグ・GitHubへの自動コミットは未対応。
- data/games.jsonでA〜Eの内蔵ゲーム種別・タイトル・反応ゲームの待ち時間を設定可能。新しいゲームコード自体はsrc/facilities.jsで追加。
- 初訪問5ポイント、アスレ25ポイント、暴室等のポイント、10ポイントで家具編集を解放。端末保存の装飾用ポイントで、サーバー管理のランキングではありません。
- 暴室は80msで復帰し、押し続けて連打できる操作を追加。
- 個人部屋の家具編集は既存の形状エディターを再利用し、3.8mの部屋境界を検証して端末保存。内装の他端末/他ユーザーへの同期は未対応。

## 共有・権限

- 図書館に共有URL本棚。オンラインの投稿者から署名なしの通常データとして共有し、受信端末に保存。永続共有用JSONを書き出せます。全員がオフラインの間の中央保存はありません。
- PC室は複数の送信先を選択可能（同時転送8件まで）。各受信者が許可します。
- 画面共有は画質/動き優先のスライダーで640〜1920幅、10〜60fpsを希望値として要求。実際の画質は端末・回線・ブラウザーに依存。
- YouTubeは公式埋め込みで選曲と開始時刻を共有。各自の再生許可が必要で、パネルを閉じる/退室すると停止。近接距離に応じた音量減衰や部屋外でのBGM再生は未対応。
- マイク/受信ミュートを頭上表示。音声の位置を変更するアカウントリンクは両方のパスワードから取得した鍵で相互署名し、パスワードは送信しません。接続中のリンク先アバターを音声の位置として利用できます。部屋のドア/入室権限も相互許可。
- OPはtamakomugi/tkk_8619。アカウント別パスワードで暗号化したP-256署名鍵を使用。マイク/受信/チャット制限、ゲスト化、退出と再入室制限、解除。署名・対象・同期名・期限を検証します。受信者の通常クライアントが守る方式なので、ストレージ削除や改造クライアントに対するサーバー側の強制力はありません。
- バージョン別接続名とhiのバージョン確認。最大6件/200ms間隔で探索し、接続を高速化。旧版とは同じ空間になりません。

## 外観

- 高品質モードで雲、塵/雨、水滴、葉の頂点シェーダーによる風。天候は共通時刻の30分区間から決定。低/標準では追加の粒子描画を省略。
- JSON外観パック（data/visual-example.json）：露出、霧、色、風、雨を指定。Minecraft用ZIP/GLSLの互換読み込みや任意シェーダーコード実行はありません。dustで塵の粒子密度を調整します。
- 建物へのUIテーマ色反映、道路側に向けた街灯、夜間の発光強化、掲示板に直接表示するイベント/滞在ランキング。
- GLBをファイルから読み込めます（10MB以下、このセッションの自分の表示）。他ユーザーへのモデル共有は従来の公開URL方式。
- 立ち/歩き/座りの正面/背面画像とGIFを端末で選択可能。状態による表示切替。これらの追加画像の他端末への配信は未対応です。
