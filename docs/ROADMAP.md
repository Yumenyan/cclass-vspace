# 実装状況と今後の範囲

2026-11-05更新。旧ロードマップで「未実装」だった各部屋には、実際に操作できる機能を実装しました。

## 実装済み

- PC室: 相手の同意を得てから送るチャンク式ファイル転送（20MB、同時8件、2分タイムアウト）、GitHub公開リポジトリの階層表示。
- 多目的室: 同ゾーンのみの画面共有、3DのVideoTextureモニター、部屋別チャット。退出時に共有と表示を停止。
- 暴室: ターゲット3体、破壊・再出現・粒子エフェクト・端末スコア。
- ゲームA〜E: ○×（2人対戦、ホスト選出、観戦）、じゃんけん、反応速度、神経衰弱、同室通知付きサイコロ。
- 図書館: configの共通リンク、端末別ブックマークの追加・削除。
- カウント: Sheets CSV取得、クォート対応の解析、静的JSONのフォールバック、再読込。
- クリエイティブ: 箱・球・円柱、追加・複製・削除・位置/サイズ/色の編集、縮小表示、実寸テスト、端末保存、JSON入出力。
- 追加空間: worldsのインデックス生成・選択・読み込み・戻る。オブジェクトは150個、JSONは宣言的な形状のみ。
- 3Dアバター: 外部参照を含まない10MBまでのGLB URL読込、身長調整、最初のアニメーション再生。
- テナント/売店: configの店舗情報とリンク、スコアで解放する色。
- 統計: オンライン中の人数と今回の滞在時間。
- 個人部屋: 持ち主だけのメモ・ラグ・植物。端末保存。
- 品質: UI刷新、探索・検索・直接移動・ミニマップ、初回ガイド、焦点管理、入力解除、移動の分割判定、一人称/追従視点・壁に遮られるカメラ、午後/夜、合成環境音、歩行/瞬き、軽量モード、静的ボックスのインスタンス化。
- 運用: Node標準APIだけで暗号化ビルド、ライブラリ同梱、公開ファイルの許可リスト、複数人統合テストと実ブラウザーテスト。

## 2.1での品質更新（2026-11-05）

ジャンプと立体的な着地、Ctrlタップ式ダッシュ、ジッターバッファ/250msまでの外挿、HTTP Dateで補正する共通のリアル時刻、4スタイル×明暗テーマ、Google Fontsの書体選択を追加しました。全16室の家具・小物・建築を詳細化し、PBRの手続き型テクスチャ、夜間照明、星/月、造形を増やした標準アバターを実装しました。低品質設定では一部の丸み・影・凹凸を省略します。

## 2.2での操作・通話・安全設定

壁の自動半透明化を廃止し、カメラ球による壁/床/天井の回避に変更。建物名ON/OFF、Pointer Lockによる見回し、既定ONの歩行時の揺れを追加しました。操作・ゲームの効果音も個別に調整できます。

VCにRNNoise、標準処理、OFFと比較録音を実装。DiscordのKrispと同じものではなく、声とノイズの状態によって品質は変わります。ブロックは受信音量、チャット範囲、アバター、自室への入室、同じ部屋の回避を選択できます。入室拒否はサーバーを使わない通常クライアント間の協調動作で、中央の権限サービスは引き続き未実装です。

## 2.3での接続・描画・チャット改善

接続試行の同時数を2件に制限し、12秒のタイムアウトと最大60秒間隔の再試行を追加。同じ接続のイベント登録と重複接続を防ぎ、接続仲介だけの切断では既存の通信を維持します。Ping/Pong、失敗したデータ/音声の再試行、バックグラウンド中の位置通知、ファイル転送時の送信待ちを追加しました。プロフィール画像を毎分再送せず、滞在時間だけを通知します。

チャットは送信者とメッセージIDで重複受信を排除します。異なるIDで同じ文章を送った場合は両方表示します。日本語入力中のEnterとキーリピートでは送信しません。旧版のIDなしメッセージは1.2秒間だけ同内容を抑制します。

自動画質、30/45/60fpsの描画上限、画素数の上限、軽量時の形状・凹凸・影の省略、遠い部屋の家具の描画省略、当たり判定の空間分割を実装。壁・屋根は不透明のままです。描画を減らしても移動計算と通信は独立して更新します。

## 外部設定が必要

GitHubのowner/repo、公開したGoogle Sheets、共有するリンクと店舗情報は運営者が用意します。既定はPeerJSの公開仲介と同梱設定のSTUN/公開TURNに依存します。専用TURNや自前PeerJSブローカーは任意設定です。公開サービスの停止・混雑や学校/企業回線の制限はクライアントだけでは解消できません。設定・回線・相手の在室状況によって利用可否が変わります。

## 今後サーバーが必要になるもの

この実装は旧構成の「GitHub Pagesだけで運用する」前提を維持しています。サーバーが強制するアカウント認証・部屋権限、オフラインメンバーへのファイル配送、恒久的なランキング、複数端末の保存同期、友達/招待/インスタンス管理、大人数向け音声中継は含みません。

VRヘッドセット、VRMの表情/リップシンク、全GLTF拡張、全身トラッキング、VRChat向けコンテンツの互換性も対象外です。近未来的な外観より、落ち着いたクラブハウスを意識したデザインにしています。
