# 3.1 更新内容（2026-11-14）

## 階段

各館の背面に、踏面40cm・段差12.5cm・幅2.4mの折り返し階段を設置。手すり・中間踊り場・各階の出入口を接続しました。以前の階移動ボタンは撤去しています。歩行の小刻みな移動ごとに足元の支持面を求め、上り下りとジャンプを扱います。館の内外をまたぐときに世界座標で足元の高さを保持し、階番号だけを切り替えます。上階から外へ出ても地面に落とされません。

全館の上り下りを移動処理で検証し、北館の1階→3階は実ブラウザーのWキー操作でも確認しました。

細い足場を周回しながら上昇する構造です。推奨はジャンプ100%。超級ではダッシュの使い分けが必要です。12段ごとにチェックポイントを保存し、落下時・HUDのボタンから戻れます（計測継続）。全員が見られるHUDに進行・秒数・ベストを表示し、完走結果を12秒表示。ゲストの記録も端末保存し、報酬はログイン後に一度だけ受け取ります。ポイントは既存の家具解放に使え、コースごとの踏破称号を設定に表示します。ログイン中は他のメンバーにも完走タイムを通知します。

記録とポイントは端末保存です。サーバーで検証したランキングではありません。

## 身長

標準アバターは実際のメッシュの境界から180cmに校正しました。名前札・吹き出しは測定対象に含めません。足元と頭頂が身長計の目盛りに合います。2Dアバターも高さ180cmを基準にし、外部GLBの既存の180cm正規化と揃えています。30/100/200%の見た目の高さを実ブラウザーで測定し、54/180/360cmになることを確認しました。身長計の操作は立った状態に戻し、目盛りの横へ移動します。

## 北館3階と編集

北館を3階建てにし、通常の部屋を並べる代わりに6基のワープゲートを置きました。URL・JSONファイル・リポジトリ内の空間から最大24件を登録し、6基ずつページを切り替えます。ブックマークはアカウント別の端末保存。外部URLはHTTPSとCORS対応の空間JSONが必要です。

北館の残っていたアトリエ3はアトリエ2へ改称（内部のテナントslot=2は維持）。

クリエイティブ部屋と広場編集室に、上から見た配置図を追加。箱・球・円柱をボタンで追加し、ドラッグ移動、右下ハンドルでサイズ変更、高さスライダー、25cmスナップ、ズーム、削除、元に戻す操作ができます。細かな数値入力は折りたたみ内に残しています。従来の3D縮小プレビュー・JSON保存/入出力・広場への反映も維持します。

## 5人接続と代替経路

- 不在枠への最大60秒の再試行待ちに対し、2秒間隔で参加者一覧を交換して、新たに見つかった相手を再探索。
- PeerJSの不在通知でslot 1とslot 10のようなIDの部分一致が起きないよう修正。
- 初期プロフィールの受信確認・再送を追加。
- 名前札の画像を位置通知のたびに作り直さず、名前/ミュート状態が変わったときだけ更新。
- 直接接続が成立しないペアは、両者と直接つながる別の参加者を介してデータを交換します。位置・チャット・プロフィールなどが対象。直接接続の試行は続け、成立したら切り替えます。
- 中継データは1ホップに制限し、接続名・経路・送信元を検証。OP操作の署名検証も維持します。設定の接続状態に中継人数を表示します。

**音声・画面共有は参加者間のデータ中継の対象外です。** これらは引き続きWebRTCのメディア接続を使います。中継できる共通参加者もいない回線の組み合わせや、通話がつながらない問題には、専用TURN/SFUなどの運用が必要になる場合があります。追加サーバーなしという既存の方針を維持しています。

実ブラウザー5台分を同時ログインさせ、各端末で5人表示を確認。特定ペアの直接接続を意図的に遮断しても、第三の参加者経由でアバター・位置・チャットが届くことを確認しました。これはローカル実RTCの回帰検証で、すべての遠隔回線での接続を保証するものではありません。
