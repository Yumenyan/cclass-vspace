# C組の居場所 · THE COMMONS

PC・スマホのブラウザーで集まれる、C組の仮想空間です。WebGL / three.js と WebRTC / PeerJS を使い、GitHub Pagesで配信できます。VRヘッドセットには対応していません。

## 2.2での更新

- **建物とカメラ:** 壁の入室時の自動半透明化を廃止。3Dでは上階や屋根も残します。窓ガラスの透過は本来の素材のままです。カメラを半径20cmの球として壁・床・天井に当て、手前へ引き寄せてから滑らかに距離を戻します。2Dの上空表示では現在階より上を省略します。
- **表示と操作:** 設定から建物名（浮動ラベルと入口の看板）のON/OFF。ドラッグに加え、Lキー・下部の「見回す」・設定の「画面をクリックしてカーソルを固定」からマウス固定を使えます。Esc、パネル表示、タブ離脱で固定を解除します。タッチ操作は従来どおりです。
- **歩行時の揺れ:** 初期設定ON。実際に接地して移動している間だけ視点を軽く揺らし、設定でOFFにできます。停止・ジャンプ・着席では止まり、「動きの演出を抑える」がONの間も無効です。
- **VC:** 強力（RNNoise）・標準（ブラウザー）・OFF、エコー対策、自動音量、入力ゲインを設定。強力モードは48kHzのAudioWorklet/WASM処理を端末内で行ってから送信します。利用できないときは標準に切り替え、その状態を表示します。設定変更中は短時間マイクが再接続されます。マイクの初期状態はOFFのままです。
- **マイク比較テスト:** VCマイクをOFFにした状態で5秒録音し、処理前/後をこの端末だけで比較再生できます。相手には送信せず、パネルを閉じると録音を破棄します。実際の環境音や声に合わせて調整してください。
- **効果音:** 操作・ゲーム・移動/交流の3分類を個別ON/OFF。音量と試聴も設定できます。操作の短い音、正解/勝利、反応ゲームの開始、破壊、サイコロ、ジャンプ、メッセージ受信を合成音で表現します。環境音の設定とは独立しています。
- **ブロック:** 「メンバー」から相手ごとに音量0〜100%、受信チャットの通常/ログのみ/拒否、アバター非表示、自分の個人部屋への入室拒否、相手と同じ部屋を避ける設定を選べます。一括制限と解除にも対応。アカウントIDを使って端末に保存し、相手の再接続後も適用します。

Discordは[Krisp](https://support.discord.com/hc/en-us/articles/360040843952-Krisp-FAQ)を採用しています。このアプリは[RNNoiseを使うWeb Audio処理](https://github.com/sapphi-red/web-noise-suppressor)であり、同じ方式や同等の効果を保証するものではありません。周囲の別の人の声、激しい突発音、小さい声などは残ったり変質したりする場合があります。処理前後のテストで確認してください。

音量・表示・チャット制限は自分の受信側だけに適用します。個人部屋への入室拒否は、持ち主が共有した拒否リストに通常のクライアントが従う協調方式です。受信したリストはそのセッション中に保持しますが、持ち主がオフラインのときに新しく参加した人へ配る中央保存先はありません。サーバーによる強制BANではなく、共有の部屋から他人を追放する機能でもありません。「同じ部屋を避ける」は、自分がその部屋に入らない/必要なら廊下に戻る動作です。

## 2.1での更新

- **ジャンプ:** Space、スマホは右下の ↥。重力・着地・家具の上への着地・屋内の天井を判定し、空中での連続ジャンプはできません。入室/エレベーター/追加空間の移動で垂直速度をリセットします。
- **ダッシュ:** Shiftから **Ctrlのタップによる切り替え** に変更しました。Ctrlを押して離してからWASDで移動します。再度Ctrlで解除。スマホはダッシュボタンです。編集欄とダイアログでは発動せず、画面を離れたら解除します。
- **ブラウザーとの競合:** 通常のページではCtrl+Wなど予約操作を完全には防げません。Ctrlを押し続ける操作は避けてください。設定の全画面ボタンでは、対応ブラウザーでKeyboard Lockも試みます。未対応/許可されない環境でもタップ式は使えます。ブラウザーやOSのショートカットを一律に無効化する実装にはしていません。
- **通信の補間:** 送信番号・送信時刻・速度・ジャンプ高さを同期。110〜350msの可変バッファで位置/高さ/向きを補間し、欠落時の予測は250msまで。以後は位置を止め、1.2秒以上更新がない相手を内部的にstale扱いにします。部屋/階/追加空間の移動と大幅な位置変更ではバッファをリセットします。急な方向転換や長い切断では補正が入ります。
- **全員共通のリアル時刻:** 日本時間（Asia/Tokyo）の24時間に合わせて朝焼け・昼・夕焼け・夜と照明が変わります。個人の昼夜切り替えは廃止しました。配信元のHTTP Dateで時計を合わせ、5分ごととタブ復帰時に再同期します。取得できない間は端末の時刻を使い、その状態を設定に表示します。HTTP Dateの秒単位精度と通信遅延による小さな差は残ります。
- **UI:** コモンズ・近未来・シンプル・ファンタジー × ライト/ダーク/端末に合わせる。フォントもテーマ連動または個別指定で端末に保存します。UI設定は共通の昼夜には影響しません。
- **3D:** 全16室の家具、窓の開口と窓枠、庇、屋上設備、植栽、街並みを追加。木・石・布・金属・芝に色/凹凸/粗さの手続き型テクスチャを使います。椅子やソファの角、キーボードのキー、本の背、食器、アバターの手・靴・顔も造形しました。静的部品はインスタンス化し、描画範囲で除外できる境界も付けています。軽量設定では影や一部の凹凸・丸みを省きます。

日本語フォントはGoogle Fontsの [Zen Kaku Gothic New](https://fonts.google.com/specimen/Zen+Kaku+Gothic+New)、[Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)、[BIZ UDPGothic](https://fonts.google.com/specimen/BIZ+UDPGothic)、[Shippori Mincho](https://fonts.google.com/specimen/Shippori+Mincho)、[Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)を選べます。ネットワークがない場合は端末の日本語フォントにフォールバックします。

## 起動とビルド

Node.js 22以上を使用します。

```sh
npm ci
npm run build
npm run serve
```

ブラウザーで http://127.0.0.1:8080 を開きます。開発サーバーも公開ファイルだけを配信し、接続はこのPC内に限定します。`index.html` をダブルクリックする方法ではなく、ローカルサーバーで確認してください。本番はHTTPSが必要です。画像・描画・PeerJS・GLBローダーのライブラリは `vendor/` に同梱しています。フォントは外部配信ですが、取得できないときは端末のフォントで表示します。

`index.html` は生成物です。編集は `src/` に行い、最後にビルドします。Pythonからの既存の呼び出し `python tools/build.py` もNode版ビルドへ転送されます。

## ログイン情報

アカウントは `tools/accounts.json`、パスワードと暗号鍵は **`tools/secrets.local.json`** にあります。今回の改修では、元の鍵ファイルがなかったため、ユーザーの承認に基づいてパスワードを再発行しました。

- パスワードの個別再発行: `node tools/build.mjs --reset Hulria`
- 追加: `tools/accounts.json` の末尾にIDを追加してビルド。個人部屋の所有者は配列の順番で決まるため並べ替えないでください。
- `tools/secrets.local.json` はバックアップし、コミット・公開しないでください。失うと既存パスワードを維持したビルドはできません。
- 「この端末でログインを記憶する」を選んだ場合に限り、パスワードを端末のlocalStorageに保存します。共有端末では選ばないでください。ログアウトすると保存した認証情報を消します。

## 運営設定

`config.json` を変更してビルドします。

- `events`: `{d,t}` のイベント一覧。
- `github`: 公開リポジトリの `{owner,repo,branch}`。未設定なら設定方法を表示します。非公開リポジトリ用の認証トークンは埋め込まないでください。
- `apps`: 共通リンク `[{name,url}]`。
- `tenants`: `[{building:"E",slot:0,name,description,url}]`。館は E/W/S/N、slotは0〜2。
- `sheetId`: Google SheetsのID。「ウェブに公開」したシートが必要です。取得できない場合は `data/counts.json` の `rows` を表示します。初期ファイルには見出しだけを入れ、架空の実績は作成していません。
- `peer` / `ice`: 自前PeerJSブローカー・STUN/TURNの設定。TURNを必要とする回線では、運営者による用意が必要です。

新しい空間はクリエイティブ部屋からJSONを書き出し、英数字・ハイフン・アンダースコアのファイル名で `worlds/` に追加します。ビルドまたは公開準備時に一覧を生成します。GitHubへの自動アップロードは行いません。

## 公開

GitHubに追加・更新した `index.html` / `vendor/` / `worlds/` / `data/` とソースをコミットし、PagesのSourceを「GitHub Actions」にします。

ワークフローは `npm run pages` 相当の処理で **公開可能なファイルだけを `_site/` にコピー**して配信します。ソース・アカウント一覧・テスト・ローカルの鍵ファイル・node_modulesは公開成果物に含めません。CIでログイン鍵を再生成しないよう、生成済み `index.html` を利用します。

## 検証

```sh
npm test
npm run test:browser
npm run test:shortcuts
npm run pages
npm run test:deployment
```

`npm run test:shortcuts` は独立したゲストタブでEdge/ChromeのCtrl+Wを検証します。ヘッドレスでの検証結果は、通常ウィンドウのOS予約操作まで保証するものではありません。

`npm test` は物理・遅延補間のテストと、2人分のブラウザー環境を模擬し、暗号解錠・PeerJSメッシュ・全16室・対戦同期・部屋別チャット・不正なパケットの拒否・保存・空間編集・入力制御を検証します。

`test:browser` は実際のWebGL描画、PC/スマホレイアウト、ログイン、検索、空間編集、共通時計とテーマを検証し、`artifacts/` に画像を保存します。Edgeがあれば利用し、別のブラウザーは `BROWSER_PATH` で指定できます。テスト専用のローカルPeerJS仲介サーバーと隔離した接続名を使い、2つのブラウザー間の実データ転送・画面共有・通話を検証します。画面共有の選択元にはテスト用の合成映像を使います。実デバイスのマイク・ディスプレイの許可画面や遠隔回線は、別途確認してください。

## 保存・通信の範囲

メモ、ブックマーク、内装、作成中の空間、ショップ解放、ベストスコアは **端末別** です。中央サーバーへの保存や複数端末間の自動同期はありません。個人部屋の内装やメモも他の利用者に配信しません。

画面共有には音声を含めません。共有中に部屋を離れると自動停止します。画面を見る側も同室にいる間だけ受信します。接続先の情報は端末の申告に依存します。

暗号化されたメンバーコードと同期名はパスワードで解錠しますが、サーバーを使わない身内向けの仕組みです。認証・ドアの権限・滞在時間はクライアントで検証しており、悪意あるメンバーに対するサーバー側の強制力はありません。HTMLを取得した第三者によるオフラインのパスワード総当たりも想定に残ります。

詳細は `docs/REFERENCE.md`、実装範囲と残る制約は `docs/ROADMAP.md` を参照してください。
